Restoring everything — if the whole database is ever lost
  1. Do not panic and do not delete anything: switch the PMS to read-only (deploy the Worker with --var MAINTENANCE:1).
  2. Download the slips and rest files of the backup you want from the table above. The login passwords are in a third file, auth, that this page never shows: fetch it with npx wrangler kv key get "bk:h:<time>:auth" --namespace-id 48710e49e880465987b706a98f70096e --remote > auth.json.gz (the time is the one in the key, e.g. 2026-10-23T18-00).
  3. Turn them into SQL: node tools/restore-backup.mjs slips.json.gz rest.json.gz auth.json.gz > restore.sql, create an empty database from worker/schema.sql and run restore.sql on it (wrangler d1 execute … --file restore.sql).
  4. Point the Worker at that database (worker/wrangler.toml), deploy, and switch maintenance off. Cloudflare's own Time Travel (any minute of the last 7 days) is the other way back: wrangler d1 time-travel restore pms-weur --timestamp=….

One slip, or a few slips deleted or edited by mistake, do not need any of this: use Find a slip in a backup above.

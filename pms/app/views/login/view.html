Technology

Three layers. No servers to babysit.

Browser & Android appPlain HTML, CSS and JavaScript modules — no framework, no build step. An offline copy of the data in IndexedDB keeps pages instant. The Android app (TWA) updates itself.
↓ HTTPS · JSON ↓
Cloudflare Workers — the edgeThe API runs in Cloudflare's data centre nearest to each desk. Logins with PBKDF2-SHA256 hashed passwords, roles, per-page access, version checks on every write, an audit log.
↓ SQL ↓
Cloudflare D1 — SQLite databaseOne source of truth for slips, rooms, transport, laundry and settings. Indexed incremental sync, soft deletes and 7-day point-in-time restore (Time Travel).
